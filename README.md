## English

### Overview

This repository provides clean, standalone Russian localization files for **survival-unlocked v1.7.1**.
It contains only configuration and text files to respect original author licensing and copyright requirements.

### Files

- `heads.yml`: All 205 heads translated.
- `config.yml`: Localized module settings.

### Installation

1. Copy `heads.yml` and `config.yml` into `plugins/survival-unlocked/`.
2. Or download pre-built `.jar` from [Releases](https://github.com/milkycloud-dev/survivalunlocked-full-russian-localization/releases/latest).

### Releases

Pre-built ready-to-use binaries (`.jar` / `.zip`) are available for download in [Releases](https://github.com/milkycloud-dev/survivalunlocked-full-russian-localization/releases/latest).

## Русский

### Описание

Репозиторий содержит чистые файлы русской локализации для **survival-unlocked v1.7.1**.
В состав включены исключительно файлы конфигурации и переводов, без бинарных сборок, с соблюдением требований лицензий авторов.

### Файлы

- `heads.yml`: Все 205 вариантов голов переведены.
- `config.yml`: Локализованные настройки модулей.

### Установка

1. Скопируйте файлы `heads.yml` и `config.yml` в `plugins/survival-unlocked/`.
2. Либо скачайте сборку `.jar` из раздела [Releases](https://github.com/milkycloud-dev/survivalunlocked-full-russian-localization/releases/latest).

### Релизы

Готовые собранные бинарные пакеты (`.jar` / `.zip`) доступны для загрузки в разделе [Releases](https://github.com/milkycloud-dev/survivalunlocked-full-russian-localization/releases/latest).
