## English

### Overview

This repository provides clean, standalone Russian localization files for **survival-unlocked v1.7.1**.
It contains only configuration and text files to respect original author licensing and copyright requirements.

### Files

- `heads.yml`: Localized Russian display names for all 205 mob head variants.
- `config.yml`: Configuration file with Russian module comments and settings.

### Installation

1. Copy `heads.yml` and `config.yml` into `plugins/survival-unlocked/`.
2. Run `/survivalunlocked reload` or restart your server.

## Русский

### Описание

Репозиторий содержит чистые файлы русской локализации для **survival-unlocked v1.7.1**.
В состав включены исключительно файлы конфигурации и переводов, без бинарных сборок, с соблюдением требований лицензий авторов.

### Файлы

- `heads.yml`: Переведенные названия для всех 205 вариантов голов мобов на русском языке.
- `config.yml`: Конфигурационный файл с пояснениями к модулям на русском языке.

### Установка

1. Скопируйте файлы `heads.yml` и `config.yml` в папку `plugins/survival-unlocked/`.
2. Выполните команду `/survivalunlocked reload` или перезапустите сервер.
